
\section{Model and Algorithm}
FL-BSA uses a dual-branch tabular generator to produce synthetic borrower portfolios from tabular lending data. In this whitepaper, fairness is evaluated \emph{post hoc} from aggregate selection counts and does not rely on training-time fairness constraints. The \ProductReleaseTag{} evidence run identifies its generator backend as \texttt{\ReleaseGeneratorBackend}; this identifier is rendered from the exact intake manifest. Branch generator configuration and hyperparameter disposition for this run are summarised in Appendix~F.

The amplification (bias-preserving) branch preserves protected-group proportions and historical decision signals so reviewers can test whether the evidence path detects the status quo. The intrinsic (de-biased) branch excludes outcome aliases before generation and then applies the configured equal-rate post-label policy, creating a descriptive comparison slice for the same protected-attribute surface. Its near-parity result is policy-imposed rather than causal: it is not a counterfactual estimate and does not show that historical disparity originates in labels. For this run, the descriptive gap is read through the historical, amplification, and intrinsic gender AIR slices reported in \Cref{tab:gender_air_slices,fig:gender_air_slices}.
