\section{Exact Identity and Digest Register}

The following values are rendered as unbroken tokens so they can be copied exactly.

\setlist[description]{style=nextline,font=\normalfont\bfseries,leftmargin=0pt,labelindent=0pt}
\begin{description}
  \item[Document version] \DocumentVersion
  \item[Publication status] \PublicationStatus
  \item[Whitepaper source] \IdentityText{\WhitepaperCommitRaw}
  \item[Product tag] \ProductReleaseTag
  \item[Product tag object] \IdentityText{\ProductTagObjectRaw}
  \item[Product commit] \IdentityText{\ProductCommitRaw}
  \item[Release workflow run] \EvidenceRunRaw{}, attempt \EvidenceRunAttemptRaw{}
  \item[Primary artifact ID] \EvidenceArtifactIdRaw
  \item[Primary intake ZIP SHA-256] \IdentityText{\EvidenceBundleShaRaw}
  \item[Runtime image digest] \IdentityText{\RuntimeImageDigestRaw}
  \item[Characterization run UUID] \IdentityText{\RunId}
  \item[Fixture SHA-256] \IdentityText{\DatasetHash}
  \item[Configuration SHA-256] \IdentityText{\ConfigHash}
  \item[Companion filename] \IdentityText{\CompanionFilenameRaw}
  \item[Companion SHA-256] \IdentityText{\CompanionShaRaw}
\end{description}

The primary intake's GitHub artifact digest, product-to-whitepaper contract digest, Gold artifact
digest, utility-source artifact digest, and derived-file hashes are in
\path{evidence/v5.0.1/publication/evidence_identity.json} and the companion
\path{MANIFEST.json}.
