\subsection{Utility reproduction}

The companion verifier hashes the supplied fixture and requires the paper-owned utility summary
bytes to match the caller-supplied PDF digest. It validates relations and aggregates inside that
bound summary; it does not read the PDF or regenerate generator outputs or model predictions. Full
reproduction requires an exact checkout of product tag v5.0.1 and its Python dependencies:

\begin{verbatim}
python3 scripts/evaluate_fixture_utility.py \
  --product-root /path/to/exact-v5.0.1-checkout \
  --fixture evidence/v5.0.1/utility/balanced_fixture.csv.gz \
  --output /tmp/utility_summary.json
sha256sum /tmp/utility_summary.json
\end{verbatim}

The product checkout is rejected unless \texttt{git describe --exact-match} returns v5.0.1 and
HEAD equals:

\end{center}

NumPy, pandas, and scikit-learn versions, a matching result has SHA-256:

repaired.

\subsection{Whitepaper build}

At whitepaper commit \IdentityText{\WhitepaperCommitRaw}, the reviewed build sequence is:

\begin{verbatim}
make publication-candidate
\end{verbatim}

The publication-candidate target runs the full test suite; regenerates strict evidence macros, old
compatibility figures, the six characterization visuals, the paper-owned summary, and the
deterministic companion; selects the reviewed demo/evaluation profile; clears prior LaTeX auxiliary
state; and emits the PDF, arXiv source, compatibility export, and hash-bound publication manifest.
It refuses a dirty source checkout so the paper commit and companion manifest agree. The complete
target is run twice in verification to confirm deterministic bytes; fonts, bookmarks, language
metadata, tags, and alternative text are separately inspected because byte determinism does not
imply accessibility. A forced-profile run of the pinned official veraPDF UA-1 validator must report
no substantive rule failures; the only permitted failure is the deliberately absent conformance
identification metadata. The candidate does not claim formal PDF/UA conformance pending human
reading-order and assistive-technology review.

\subsection{Source hierarchy}

The exact producer intake remains unchanged except for the deterministic whitepaper-consumer stamp.
Paper-owned corrections live under \path{evidence/v5.0.1/publication/}. This separation permits a
reviewer to distinguish original evidence, a corrected interpretation, and a derived study. The
companion manifest hashes all three layers and states that the candidate is not published.
