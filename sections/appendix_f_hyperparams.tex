\section{Selected Generator Configuration}

The exact release uses the first-party evidence-native generator for both branches. The branch
certificates record a profile-based fit, deterministic seeds, categorical columns, protected
attributes, outcome handling, output-size targets, and branch-specific label policy. Parameters
that do not apply to the selected algorithm are reported as not applicable rather than populated
with values from another model family.
